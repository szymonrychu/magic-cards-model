## Tooling and test fixes made during the dry run

- F2 commits the overlap json it used (scripts/split/state/f2-overlap.json); port_branch re-splits F2 with exactly those edges
- codemod applies the surface snapshot to class-mode manifests too (game facade kept 292 imported names off)
- surface test counts the package __init__ as a defining module (Game stays in models/game/__init__)
- hygiene check (d) resolves facade names through sibling packages too (machines/effects/ after F1)
- baselines test count gate excludes the split's own tests (F2 adds tests/test_dispatch_order.py)
- F2 regenerates the committed dispatch fingerprint baseline; F3/F4 compare the fingerprint against it plus pre-split results and chain sets
- gates --keep <json> saves the gate's measurement for the freeze record
- manifest_lib reads a split module's source from the commit that deleted it (manifest tests stay green after F1)
- suite time gate fails on a slowdown over 5%, not on a faster run
- suite measurement records the failing test ids, the gate names them
- Chain.run calls a cached straight-line runner per segment (F2 effects sweep 5.75s -> 5.58s vs 5.40s monolith)
- timing gates compare CPU time when both sides measured it (r2: load 36 on 12 cores doubled wall time at F3, CPU time unchanged)
- import CPU time is the minimum of 7 runs (r4: median of 5 moved +14.6% with machine load)
- a suite timing violation is re-measured A/B (pre-split commit, then this tree) before it fails the gate (r6: F1 pure move read +24% CPU at load 14)
- class mode folds Game's mixins into one generated base via a metaclass (r7 port gate: eleven mixin bases read +5.6% suite CPU, A/B +6.7%)
- rewrap the codemod class-mode docstring to 100 columns
- finish rewrapping the codemod class-mode docstring (lint green)
- the goldens hash skips bytecode caches (r5-r8 read a different hash on every fresh worktree from tests/golden/__pycache__ mtimes)
- a suite run that exits nonzero without a failed test is a named violation with its output tail (r11: venv broken by the /tmp cleaner, mise run test exited 4 with no reason logged)
- rerun a suite's failed tests once alone; failures that pass there are RERUN notes, not gate failures (r12 full-F4e: the CPU-budget card_support test flaked under load, test:full passed it on the same tree)
