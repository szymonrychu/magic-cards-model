# Project memory

Standing conventions and corrections, recorded as they came up. One memory
per file in `memory/`, indexed here. New memories go in this directory and
this index - not into any per-user directory - so the project stays the single
home of its own memory.

- [No mocks, scenario tests only](memory/no-mocks-scenario-tests.md) — every test uses real Scryfall cards through the Scenario harness; mocks are banned
- [Never recall MTG rules from memory](memory/never-recall-mtg-rules-from-memory.md) — every rule and CR number must be verified with knowledge_search; training data is wrong
- [magic-cards-model is a rules engine](memory/magic-cards-model-engine-goal.md) — the target is playable PvP MTG, not a card database
- [Subagents on the cheaper model](memory/subagents-on-cheaper-model.md) — pass model: "sonnet" on every Agent dispatch unless told otherwise
- [Engine fixes land in the engine](memory/engine-fixes-in-engine-only.md) — no API/frontend workarounds for rules gaps; only the most correct engine implementation
- [User examples become test cases](memory/user-examples-become-testcases.md) — every play-testing example the user reports is converted to a scenario test
- [Restart the API server after fixes](memory/restart-api-server-after-fixes.md) — uvicorn caches code at boot; kill by port (lsof -ti :8000), and verify the serving process predates no fix
- [Silent-default dispatch tables](memory/silent-default-dispatch-tables.md) — every defect class the loop has found is a lookup that defaults instead of refusing; fail closed and shout on a miss
- [Effect registry is the dominant gap](memory/effect-registry-is-the-dominant-gap.md) — most cards resolve and do nothing; the measured survey, per-deck dead-card counts, and the ranked order of work
- [Verify agent findings against the engine](memory/verify-agent-findings-against-the-engine.md) — adjudicators and reviewers each produce confident wrong claims; reproduce before acting
- [Harness deadlock defaulted every decision](memory/harness-deadlock-defaulted-every-decision.md) — 18 decisions per game timed out unanswered; re-check past "engine did nothing" reports
- [Autonomous playtest loop](memory/autonomous-playtest-loop.md) — play, report, confirm with opus, fix globally with sonnet, repeat until three clean games per deck pair
- [No commits: git checkout destroys work](memory/no-commits-git-checkout-destroys-work.md) — this repo has zero commits, so git restore/checkout/stash overwrite with an ancient index blob; recover from ~/.claude/file-history
- [Agent playtest launch](memory/agent-playtest-launch.md) — two AI players as Agent-tool subagents driving seat_cli.py: sonnet, one-session prompts, no curl (seat hides the opponent's hand), vet their reports against the CR
- [Combat declarations skip the live provider](memory/combat-declarations-skip-the-live-provider.md) — resolved 2026-09-07 (T8) by deleting DecisionScript.provider entirely, not by wiring it up; every asker in machines/decisions.py now answers one way (script, tape, pause, default)
- [Delayed trigger serialization vs. a game.py isolation lock](memory/delayed-trigger-serialization-game-py-isolation.md) — DelayedTrigger.effect became a discriminated union while game.py was locked; a narrow before-validator plus singleton-named specs bridge its 3 legacy call sites instead of blocking
- [KeywordActivation round trip and object identity](memory/keyword-activation-round-trip-identity.md) — typing AbilityOnStack.keyword_activation/.unless_payment correctly still left a decoded KeywordActivation.card as a copy, not the battlefield object; _equip_effect mutated the copy until it re-resolved by id
- [could_pay_mana_cost predicate](memory/could-pay-mana-cost-predicate.md) — the pure affordability predicate could not build a CostPayment at all (for_total registers a pool into open_payment_pools); _SpendContext duck-types its three read-only fields instead, and Card became frozen=True to make the new ability-parse caches sound
- [Flow-based auto-tap source grouping](memory/flow-based-auto-tap-source-grouping.md) — max-flow replaced auto-tap's exponential search, but only after grouping a permanent's several abilities into one provider node; two independent nodes for Eldrazi Temple's {C}/{C}{C} let capacities sum (1+2=3 from one land, one {T})
- [Legal actions enumeration](memory/legal-actions-enumeration.md) — legal_actions never gates on affordability (CR 118.6); why_cannot_cast_now waved a land through with no type check (now refused at the source, Casting itself, CR 305.1); hoisting _auto_tap_candidates needed a spend-independent/spend-dependent split, not just a cache; PERMISSION/STATIC alt-costs are ported into Game.alternative_costs_for and a targeted off-battlefield activation (Boseiju's Channel) reports UNKNOWN instead of vanishing — both were wrongly deferred first pass, fixed second pass
- [Game.schema_version fails closed](memory/game-schema-version-fail-closed.md) — a required no-default field plus a mode="before" validator refuses a mismatched or missing version; the exception subclasses RuntimeError, not ValueError, because pydantic-core rewraps ValueError into a generic ValidationError and would swallow it
- [Scenario round-trip/replay invariant](memory/scenario-round-trip-replay-invariant.md) — every scenario now proves it round-trips and replays; found ~30 Game/token/keyword methods minting ids with no `_id_allocator_scope` open (ids.py's own list was incomplete), an unseeded `random.Random(None)` in cascade's bottoming, a copy-of-a-permanent-spell that never actually became a TokenState, and DecisionScript.provider crashing model_dump with no exclude=True; a global default-allocator design was tried and reverted for breaking legal_actions' purity guarantee
- [Callables became discriminated unions](memory/callables-became-discriminated-unions.md) — 2026-09-07. A keyed registry still defaults silently on an unknown key at decode; a discriminated union on `kind` refuses instead, and carries the closure's own captured parameters as typed fields, which a string key never could
- [Pause is a snapshot plus a tape](memory/pause-is-snapshot-plus-tape.md) — 2026-09-07. Not a `pending` field on `Game`: a half-applied mid-resolution game is not a legal state to persist, so a paused game is (last committed Game, the command, the answers so far) and resuming re-derives the identical decision via ids.py's deterministic allocator
- [Announcement is atomic](memory/announcement-is-atomic.md) — 2026-09-07. `Casting.model_post_init` runs every refusal (CR 305.1, CR 117.1a, restrictions) before CR 601.2a ever moves the card to the stack, so an illegal cast is refused with a reason instead of half-applied
- [DecisionPending is a BaseException](memory/decision-pending-is-a-baseexception.md) — 2026-09-07. Measured: 3 real `except Exception:` sites and 42 real `except ValueError:` sites in `src/` around effect resolution; any of them catching an `Exception`-derived pause would silently turn it into "the effect did nothing", so it derives from `BaseException` instead
- [Exile is a shared zone](memory/exile-is-a-shared-zone.md) — 2026-09-07. `player.add(state, Zone.EXILE)` builds a per-player exile pile the rules have no name for (CR 400.1, CR 406.2); it is invisible to `Game.exile`, to `all_targetables`, and to every seat's board, and `Player.cards_in(Zone.EXILE)` hides it from tests
